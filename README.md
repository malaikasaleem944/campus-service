# Campus Service

## Project Goal
Campus Service is a simple JavaScript project
developed to demonstrate DevOps practices,
version control and automated testing.

## How to Run Tests
1. Install Node.js.
2. Open the project in VS Code.
3. Open the terminal.
4. Run npm test.

## Tools Used
- Visual Studio Code
- JavaScript
- Node.js
- Git
- TortoiseGit
- GitHub
- GitHub Actions
